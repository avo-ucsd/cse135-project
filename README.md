# Use of AI
We used Claude AI to help us efficiently implement all the project requirements once we had thought through the best course of action. AI is a dual-edged sword as it can help expediate the process of programming but actual learning of the material is lost during the process. While it may feel like we are being more productive we are actually wasting time dealing with the AI's mistakes and feeling frustrated that it does not do what we want. For a project like this where we have a limited amount of time, AI is not only useful but necessary to meet the time constraints. As long as we are cautious with what AI outputs and make sure we are understanding what is happening, it is a useful tool.
